Commercial Target Studio

Quarterly target-setting for KAM client reviews. Uses all four yearly quarters, seasonality, trend, backtested model blending, and commercial capacity checks.

Currency fixed: EUR All 4 quarters used 10% minimum growth rule Client-facing insights

How To Use This Tool

  • Enter complete quarterly history first (all Q1-Q4 values for each year).
  • Set commercial assumptions (win rate, pipeline, conversions, capacity).
  • Run the engine and present the 3-level ladder: Minimum, Commit, Stretch.

Scenario A (Stable Client): Keep ambition low (2-5%), rely on trend + seasonality.

Scenario B (Growth Push): Raise ambition (6-12%) only if pipeline coverage is strong.

Scenario C (Volatile Portfolio): Use conservative assumptions and explain confidence limits.

Important: The minimum target always enforces at least +10% growth.
